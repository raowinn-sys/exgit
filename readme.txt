markdown = 
langage balisage léger, permet mise en forme de texte brut
grâce à symboles simples du clavier, sans utiliser balises html complexes
avantages =
texte brut + légereté -> fichers markdown sont légers et simples
indépendance logiciel -> pas besoin de logiciel payant/propriétaire pour ouvrir/modifier fichier
pérennité + accessibilité -> les docs restent lisibles/exploitables sans risque d'obsolescence
simplicité lecture/écriture -> html demande balises alourdissant lecture, pas besoin avec markdown
conversion automatique -> transformation simple de markdown en html/pdf/epub

markdown  exemple : #Titre principal
                    ##Sous-Titre
                    ###Sous-sous-titre
